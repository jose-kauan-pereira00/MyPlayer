# Changelog

## [1.0.0] - 2026-06-27
### Lançamento Inicial (Initial Release)
* **Funcionalidade:** Implementação do player de música básico com suporte a reprodução local.
* **Funcionalidade:** Lista de faixas carregada a partir do armazenamento do dispositivo.
* **UI:** Interface desenvolvida com Jetpack Compose seguindo princípios de Material Design 3.
* **Controles:** Botões de reproduzir, pausar, avançar e retroceder implementados.
* **Otimização:** Suporte para execução em segundo plano para manter a música tocando com o app minimizado.
